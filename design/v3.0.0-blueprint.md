# pawn v3.0.0 Blueprint — ZCode 오마주 프론트엔드 리디자인

> 작업 언어: 한국어. 최종 DESIGN.md는 영어로 유지 (레포 컨벤션).
> 브랜치: `v3.0.0` (master에서 분기). 기능 코드는 손대지 않음. 오직 프론트엔드(토큰 → 컴포넌트 CSS → 모션 → 홈).

## 0. Locked decisions (2026-10-07, 장원)

1. ZCode 디자인 시스템의 **구조를 거의 그대로** 가져온다. pawn 현 컬러(Cursor 파생)는 오리지널이 아니므로 미련 없이 교체.
2. pawn 기능 구현(65개 컴포넌트의 동작, 스토어, IPC)은 그대로. 껍데기만 교체.
3. 실행은 opencode (Zen 무료 티어) + ponytail 플러그인. 덕구는 설계·검수, opencode는 타이핑.
4. 페이즈 단위로 커밋. 각 페이즈 종료 조건: `npm run typecheck:web` 통과 + (UI 페이즈는) dev:web 스크린샷 검수.

### 1.3 타이포 스케일 (Phase 2 스펙)

ZCode `text-ui-*`를 그대로 도입. `--ui-font-size: 14px`를 기준으로 상대 계산 → 설정에서 기준값만 바꾸면 전체 비례 스케일.

```css
--ui-font-size: 14px;
--text-ui-xl: calc(var(--ui-font-size) + 4px);      /* 18px, h1 */
--text-ui-lg: calc(var(--ui-font-size) + 2px);      /* 16px, h2 */
--text-ui-base: var(--ui-font-size);                /* 14px, 본문/버튼/제목 */
--text-ui-caption: calc(var(--ui-font-size) - 1px); /* 13px, 보조문 */
--text-ui-sm: calc(var(--ui-font-size) - 2px);      /* 12px, 헬퍼/툴팁/인라인코드 */
--text-ui-xs: calc(var(--ui-font-size) - 4px);      /* 10px, 뱃지/카운터/단축키 */
```

기존 `--font-xs|sm|md|lg|xl|2xl|3xl` 사용처를 위 스케일로 교체 (`--font-md`(13px) → `--text-ui-caption` 등, 의미 기준 매핑).
폰트 스택은 유지: Inter → Pretendard Variable → 시스템 (한글 대응), JetBrains Mono (코드/경로).
규칙: Mono는 경로·명령·코드·해시에만. 뱃지/카운터 외 10px 이하 금지.

### 1.4 모션 (Phase 5 스펙)

ZCode 철학: "빠르고 low-drama. fade/zoom/방향성 slide만. 스프링/장난스러운 모션 금지."

```css
--dur-instant: 80ms;    /* 유지 */
--dur-fast: 150ms;      /* 120ms → 150ms, transition-colors 기본 */
--dur-med: 260ms;       /* 180ms → 260ms, 등장 모션 */
--dur-slow: 300ms;      /* 280ms → 300ms, collapsible */
--dur-stream: 900ms;    /* 신규, 스트리밍 텍스트 페이드 */
--ease-out-soft: cubic-bezier(0.22, 1, 0.36, 1);  /* 유지, 주 easing */
```

keyframes (신규):
- `pawn-stream-text-in`: 900ms ease — 스트리밍 텍스트 페이드
- `pawn-draft-waterfall`: 260ms var(--ease-out-soft) — 추천/목록 등장 (clip-path + translateY)
- `pawn-collapsible-up/down`: 300ms — 접기/펼치기

철칙: 인터랙티브 요소는 `transition-colors`만. `transition-all` 금지 (ZCode button.tsx 주석과 동일 이유).
`prefers-reduced-motion` 전역 대응 유지.

### 1.5 서피스 & 그림자

- 레이어링은 bg 대비 + 1px border. 그림자 자제.
- `--shadow-elevated: none` 유지.
- 신규: `--shadow-popover` (메뉴/팝오버/다이얼로그용, 은은하게), `--shadow-toast` (토스트용). 값은 검수 시 조정.
- 컴포저: `rounded-2xl`(16px) — ZCode 공식 예외를 그대로 오마주. pawn `--radius-lg`(12px) → 컴포저만 16px.

## 4. opencode 실행 프로토콜

- 작업 디렉토리: `~/workspace/pawn`, 브랜치 `v3.0.0`
- 호출: `opencode run` (기본 모델이 이미 Zen free). ponytail 플러그인 전역 설치済 — 매 턴 룰셋 자동 주입
- 페이즈당 1회 호출, 프롬프트에 본 블루프린트의 해당 섹션 번호 명시
- 작업 후 `npm run typecheck:web` 실행, 실패 시 수정까지. UI 페이즈는 `npm run check` 권장
- 페이즈 완료마다 커밋: `git commit -m "v3.0.0 phase N: ..."`
- 절대 금지: 기능 로직 변경, 새 의존성 추가, `transition-all`, 하드코딩 hex (교체 대상)

### pawn 프로젝트 컨벤션 (AGENTS.md 준수 — 위반 시 CI 실패)

- **i18n**: 모든 UI 문자열은 `t()` 경유. 키는 4개 로케일(en/ko/ja/zh) 전부 추가 — 테스트가 parity 강제. 한국어 해요체, 영어 sentence case. Phase 4의 시간대별 인사(6구간)는 키 6개 × 4로케일.
- **CSS**: kebab-case + 컴포넌트 prefix, global.css 토큰만 사용. CSS modules/Tailwind 금지.
- **UI에 이모지 금지** — SVG 아이콘.
- `window.api`는 optional chain + fire-and-forget에 `.catch(() => {})`.
- 새 `any` 금지 (TS strict).
